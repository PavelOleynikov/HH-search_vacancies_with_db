# Приложение для поиска данных о компаниях и их вакансиях

## Описание

Проект представляет DBManager — это приложение для работы
с базой данных, предназначенное для управления информацией
о компаниях и вакансиях. Оно позволяет выполнять различные
операции, такие как получение списка компаний с количеством
вакансий, поиск вакансий по ключевым словам и ссылок на них, и получение
информации о вакансиях с зарплатой выше средней.

### Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/PavelOleynikov/HH-search_vacancies_with_db.git
```

2. Установите необходимые зависимости:

```
Убедитесь, что у вас установлен Python 3.13.5 и poetry.
Затем выполните:

poetry add psycopg2
```

3. Настройте базу данных:

```
Перед запуском приложения создайте базу данных PostgreSQL
и настройте параметры подключения в коде.
```

### Использование:

1. Создайте новый проект.
2. Запустите скрипт: python main.py
3. Интерфейс пользователя:

После запуска приложения вы увидите меню с доступными опциями:

    * Получить список всех компаний и количества вакансий у каждой компании
    * Получить список всех вакансий с указанием названия компании,
      названия вакансии, зарплаты и ссылки на вакансию.
    * Получить среднюю зарплату по вакансиям.
    * Получить список всех вакансий, у которых зарплата выше средней по всем вакансиям.
    * Получить список всех вакансий по ключевому слову.
    * Выход
      
    Введите номер опции и следуйте инструкциям на экране.

### Описание классов, методов и функций:

HeadHunterAPI

```
Класс для работы с API hh.ru.
```

методы:

* get_vacancies: метод получения списка вакансий по указанному id компании.

Модуль - connect_db

```
Модуль для подключения к БД и создания таблиц
```

функции:

* create_database: функция для создания базы данных
* create_tables: функция для создания таблиц.

DBManager

```
Класс для работы с базой данных
```

методы:

* get_companies_and_vacancies_count: метод для получения списка всех компаний и количества вакансий у каждой компании
* get_all_vacancies: метод для получения списка всех вакансий с указанием названия компании,
  названия вакансии и зарплаты и ссылки на вакансию
* get_avg_salary: метод для получения средней зарплаты по вакансиям
* get_vacancies_with_higher_salary: метод для получения списка всех вакансий,
  у которых зарплата выше средней по всем вакансиям
* get_vacancies_with_keyword: метод для получения списка всех вакансий,
  в названии которых содержатся переданные в метод слова
* close_db: метод отключения от БД

Утилиты:

- fill_tables: функция заполнения таблиц данными о работодателях
  и их вакансиях
